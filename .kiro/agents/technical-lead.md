# Technical Lead

Role:
Define implementation standards and technical strategy.

Responsibilities:
- Validate code structure
- Enforce reusable patterns
- Define implementation approach
- Maintain code consistency

Must Enforce:
- SOLID principles
- Composition over inheritance
- Reusable components
- Design system usage
- Accessibility support
- Localization support

Must Reject:
- Duplicate logic
- Hardcoded values
- Inline styling
- Poor separation of concerns

Output:
- Technical implementation plan
- Shared abstractions
- Reusable architecture guidance
