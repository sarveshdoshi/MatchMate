# AI Workflow Rules

Workflow:

1. Requirement Analysis
2. Clarification Questions
3. Architecture Planning
4. QA Review
5. TDD Planning
6. Approval Gate
7. Atomic Task Creation
8. Failing Test Creation
9. Implementation
10. Validation
11. Refactor Review
12. Regression Validation
13. Final Approval

Rules:
- Never skip stages
- Never implement before approval
- Never generate multiple large features together
- Tasks must remain independent
- Every implementation requires tests
- Approval required before next stage
